# Seamless chapter cross-loading (no explicit chapter navigation)

The reader auto-loads the next/previous chapter archive from the series as the user scrolls near the content edges, preserving scroll position across the boundary, instead of requiring an explicit "open next chapter" action. This is the product's differentiator (continuous reading), but it deliberately widens the trust scope: opening one user-chosen file causes sibling `.cbz` files in the same directory to be opened and decoded without explicit selection. Accepted as a product decision; the win for the reading experience outweighs the sibling-file trust widening for a single-user desktop reader. Security budget (per-entry decompression cap, bounded in-flight dispatch) applies equally to auto-loaded siblings.
