## Purpose

A desktop comic and manga reader application designed for browsing, loading, and reading Comic Book
ZIP (CBZ) archives. It provides optimized document viewing across different reading modes (such as
Manga and Webtoon) using viewport-aware memory caching.

## Domains

This system is organized into the following domains:

| Domain | Description | Spec |
|--------|-------------|------|
| Cache | Manages in-memory decoded page textures and enforces memory limits by evicting pages furthest from the viewport. | [spec.md](../cache/spec.md) |
| Cbz | Encapsulates loading, page counting, dimension extraction, decompression, and image decoding for Comic Book ZIP (CBZ) archives. | [spec.md](../cbz/spec.md) |
| Ui | Constructs and styles chapter transition banner UI components displaying chapter information and page count. | [spec.md](../ui/spec.md) |

## Requirements

### Requirement: SystemCapabilities

The system SHALL provide the following capabilities:
- Monolithic desktop architecture implemented in Rust with native GUI widgets
- Viewport-distance-based texture eviction within MemoryManager to bound memory consumption during large comic/manga viewing
- Decoupling of archive decompression (CbzArchive) from UI presentation (PageWidget, ReaderView)
- Modular reading modes supporting distinct layouts such as Manga and Webtoon
